# 48×8 LED Chaser Display

An Arduino-based LED matrix project designed to display scrolling text and LED animation patterns using a 48×8 LED matrix.

## Overview

This project explores digital electronics, embedded programming, shift registers, and LED multiplexing to create a scrolling LED display.

The circuit was developed and tested using Tinkercad simulation.

## Features

* 48×8 LED matrix configuration
* Scrolling text display
* LED animation patterns
* Arduino-based control
* 74HC595 shift-register interface
* Circuit simulation using Tinkercad

## Hardware Components

* Arduino Nano or Arduino Uno
* 384 LEDs
* 74HC595 shift registers
* 2N2222A transistors
* Current-limiting resistors
* Connecting wires
* Suitable power supply

*The final component quantities and specifications will be documented according to the actual circuit.*

## Circuit Design

The circuit uses shift registers to expand the Arduino's available digital outputs. Multiplexing controls the LED matrix by activating rows and columns in sequence.
